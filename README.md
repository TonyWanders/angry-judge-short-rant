A program that writes one short funny rant about an everyday annoyance to
`/output/entry.txt`, for the make.fun competition
[Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046).

Run it with Python 3:

```
python3 main.py
```

It writes the rant below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The rant is exactly 400 characters, inside the 1 to 400 gate.

## The rant

```
The office printer has one job and it hates doing it. It jams only when the boss is standing behind you, spits out one blank page as an insult, then flashes PC LOAD LETTER like that means anything to anyone alive. I have fed it paper, toner and my last shred of patience, and it still looks at me like I am the problem. It is not a machine. It is a tiny grey landlord collecting rent in jammed paper.
```
